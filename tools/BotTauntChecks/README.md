# Normal combat taunt checks

Run `pwsh -NoProfile -File tools/BotTauntChecks/Verify.ps1` and
`pwsh -NoProfile -File tools/BotTauntChecks/Verify-Installed.ps1` from the repo.

The harness compiles the production adapter and version guard. Its separate
SAIN.Preset.Shared fixture preserves the enum assembly boundary and rejects a
compiled regression mutant that incorrectly searches for that enum in SAIN.dll.
Boundary doubles describe the native ownership contracts; a dynamic method executes the actual
production transpiler's boolean substitution and original branch. The ordinary,
retired, foreign component, PFT, other-personality and native Mind veto controls
are also compiled into deliberate production-source mutants and must fail their
specific assertion. Source hashes and run transcripts live under ignored `obj/`.

The independent Cecil check reads installed SAIN 4.5.1 IL and verifies the exact
field/branch seam, reflected members, native timer/chance/enemy decisions and
outer CanTalk dispatch. A newer installed DLL requires a new review of this
offline oracle; runtime admission still uses Arena's existing 4.5.1+ policy and
checked reflection contract.

These checks prove adapter behavior and installed API shape, not audible native
speech. A GPU raid with DeveloperMode emits at most three distinct-body
`Arena SAIN Normal combat taunt eligible` lines per world after a real operand
override. The cached CanTaunt and shared personality remain false by design.
Native SAIN speech may still be declined by cooldown, chance, enemy context,
distance, speaker priority or PFT ownership. Actual playback retains SAIN hearing.
