# Translocator item checks

Run `pwsh -NoProfile -File tools/TranslocatorItemChecks/Verify.ps1` from the repository. Optional `-RuntimeRoot` and `-ItemDatabase` select an installed SPT copy; both inputs are read only.

The standalone .NET 10 project links production registration, exclusions and xUnit cases. It compiles the actual client confirmation method, capability property and router capability expression, extracted with exact unique anchors. Only their transport/logging boundaries are doubled.

Installed SPT checks execute its profile-load guard, clone API refusal, property override and bulk flea-unlock methods on isolated objects, with unprotected and ordinary-item controls. They print the tested Core version and SHA256. They do not start SPT, construct SaveServer, read profiles or write runtime files.

The shared source-fault runner compiles every deliberate defect and requires the intended assertion to reject it. Compile failures and surviving defects fail verification. Source files are never rewritten. The project has no mod project reference or deployment target.

Passing establishes registration, server/client capability and ordinary-pool exclusion behavior. Native equip/input, textures, inventory supply, teleport, profile restoration and gameplay acceptance belong to the integrated client tests; this harness does not establish them.
