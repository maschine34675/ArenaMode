# Bot agility checks

`pwsh -NoProfile -File tools/BotAgilityChecks/Verify.ps1`

Links the production agility adapter and exact shared bot admission. Boundary
doubles are derived from this repository's movement harness and expose only the
native API/data shapes used here. Tests validate scalar tuning, independent
read-to-policy dispatch, scope isolation and failures; they do not simulate
Unity animations, Harmony detours or native navigation.

Mono.Cecil checks the installed native methods and ten IL sites, baseline
Vector2 semantics and existing overweight thresholds. Ten compiled mutation
controls must fail at named assertions, including wrong policy dispatch.
Production is restored/rechecked; input hashes reject concurrent edits. Build
output and evidence stay under tools and ignored `artifacts/bot-agility-checks/`.
