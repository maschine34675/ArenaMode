# Original EFT Arena UI artwork

These PNGs were supplied by the user from their Escape from Tarkov Arena
installation and copied unchanged from the 2026-09-29 UI extraction. Copyright
and other rights remain with the original game rights holders. No free or
redistribution licence has been established for these files.

They are NOT covered by the mod's code licence, the independently authored
RaidInfoPanels icons, or any third-party MIT/CC0 notices. This integration is
for the user's authorized private installation. Review distribution rights
before including this artwork in a public release.

SOURCES.json records each exact exported filename, original asset location,
available object identity, pixel size and SHA256. The mod's descriptive filenames
are local presentation choices, not claims about Arena's original icon mapping.

The team-panel PNG retains its original bytes. Its private in-memory texture
is desaturated before tinting so custom friendly/opponent colours remain valid.
All other icons render unchanged. No font, game code or entire asset bundle is
copied. Missing/corrupt art falls back to the existing textual information.
